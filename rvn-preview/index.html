01 / The premise

The games aren't the problem. The cost of connecting them is.

In one illustrative legacy deal, an operator pays 7% of game GGR, the studio retains 5 percentage points, and the aggregator receives 2. The studio may collect the full 7% and pay the aggregator itself. Actual contracts vary.

Railven separates the technical connection from the content deal. Operators and studios negotiate game royalties directly; Railven charges transparent processing fees and published studio catalogue membership, never a percentage of GGR.

03 / Two payment routes

Who pays for the rails?
Either side. Never both.

The studio and operator remain free to agree the game royalty. Railven's processing fee is billed to one designated party for each authorised route.

A / Operator-funded

Operator pays Railven.

Operator pays the studio its agreed content royalty and separately pays Railven's metered processing bill.

Operator → studio: content royaltyOperator → Railven: processing usageStudio → Railven: catalogue membership

Where the old aggregation margin is removed from the content deal, the operator captures the processing saving.

B / Studio-funded

Studio pays Railven.

Operator pays the studio under their negotiated agreement. Studio pays Railven for the processing activity and its catalogue membership.

Operator → studio: agreed content feeStudio → Railven: processing usageStudio → Railven: catalogue membership

The studio initially captures any saving. The operator only saves if their content agreement is renegotiated.

No double billing for rounds or launches. Catalogue membership pays for the standing studio integration and tools; the processing payer covers transaction activity. Content agreements, game approvals and regulatory obligations remain the parties' responsibility.

08 / Straight answers

The details
matter.

Does Railven negotiate or replace studio royalties?

No. Operators and studios negotiate game content agreements directly. Railven provides authorised technical routing and never takes a percentage of game revenue.

Who pays Railven's processing fee?

Either the operator or the studio for each authorised route, as agreed between them. Never both for the same round or launch. Studios separately pay their published catalogue membership.

What does a studio membership buy?

A standing technical integration, eligible live catalogue management and tier-appropriate conformance, release and monitoring workflows. Membership is required for a studio's active production catalogue. Sandbox evaluation can begin before that commitment.

Will Railven sell a studio's games to operators?

No. Each studio's commercial team is responsible for finding operators, negotiating royalty terms and securing launches. Railven does not promise operator placement or revenue.

Do wins and losses create different charges?

No. The intended unit is a completed logical game round, charged identically regardless of outcome. Routine balance, settlement and retry messages are included within a defined normal-use envelope.

Will every operator save money?

No. Savings depend on traffic, existing fees and the applicable revenue base. In the studio-funded route, the saving initially belongs to the studio unless it renegotiates the operator agreement.

Is Railven live and licensed?

Not yet. Railven is a pre-launch concept seeking design partners. Production systems, supported markets, rights, regulatory permissions and commercial terms require development and validation.
