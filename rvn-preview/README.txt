1. In the GitHub repo that serves tractionfactory.co, create a folder at the repo root named:
   rvn-preview
2. Upload index.html from this package into that folder.
3. Commit to the branch used by GitHub Pages.
4. Visit https://tractionfactory.co/rvn-preview/

Important:
- The page is self-contained. No asset folders are required.
- It has noindex, nofollow, noarchive and nosnippet directives.
- Do not link it from the Traction Factory homepage.
- Do not add it to the sitemap.
- Contact buttons email hello@tractionfactory.co.
- This is hidden, not secure. Anyone with the URL can access it.

Optional extra:
Add the following line to the main site's root robots.txt:
Disallow: /rvn-preview/
